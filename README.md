# Construction Wand — Build Entire Walls in Seconds

Construction Wand 9minecraft Mod lets you place huge rows of blocks all at once. Instead of clicking one by one, you can build a whole wall, floor, or path in a single second. The wands take blocks straight from your inventory to build the shape you want. This saves you hours of time when making big houses or long roads. It works well in survival mode by using your own materials and taking durability damage over time.

## What this build is

An unofficial rebuild of **ThetaDev**'s original work, kept running on current Minecraft releases by 9Minecraft Studios. Not affiliated with the original author and not endorsed by them.

Most of the porting work sits in the mixin layer. Each Minecraft release moves or renames the methods this mod hooks into, so the hooks are re-pointed and re-tested against that version rather than rewritten. The behaviour underneath is upstream's and is deliberately left alone — that is the part that makes the mod feel right, and it is not ours to redesign.
